## 兼容与回滚

- 不修改 Harness Web 内容，只注入单个带命名空间的 DOM 节点。
- 设置引导使用独立命名空间节点与本地已读标记；不写入 Harness 设置命名空间。
- Chat 键盘脚本只匹配可编辑元素：组合输入停止网页传播但允许输入法确认；非组合态无修饰普通 Enter 在多行编辑器中交回网页原生逻辑；修饰键与单行输入继续拦截，空白多行输入由网页保持不发送；非编辑控件完全不受影响。
- 语言偏好仅影响原生 SwiftUI/AppKit 文案和应用注入的本机辅助 UI，不调用第三方网页语言接口；移除语言资源和设置项即可回到中文默认界面。
- 删除 user script 和 ContentView 运行态分支即可回到原生外壳。
- 欢迎、启动、失败和日志 sheet 保持现有实现。

## Codex 5.5 审核清单

- 运行态是否确实只剩一层主界面。
- 脚本是否幂等且不依赖上游 class 名。
- 注入消息是否不携带敏感信息。

- 是否没有计划外修改进程管理。
