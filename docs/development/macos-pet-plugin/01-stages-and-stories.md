## AT-501：定义宠物清单模型

用户故事 US-501：作为 HarnessDock 用户，我希望应用能安全理解 Codex 宠物包，以便复用已有宠物而无需安装可执行扩展。

### 范围

- 解码 `pet.json` 的 ID、名称、版本、作者、描述、图集文件名和可选几何字段。
- 默认采用 192×208 单格、8 列、9 行，并拒绝路径逃逸和不合法几何。

### 验收标准

- Given 最小合法清单，When 解码，Then 图集文件和固定几何有正确默认值。
- Given 图集路径指向包目录外，When 校验，Then 包被拒绝。

### 验证方式

- XCTest 与 `HarnessDockCoreChecks` JSON 用例。

### 完成定义

- 公共模型和验证错误可由 App 目标调用，自动检查通过。

## AT-502：定义动画行和帧时序

用户故事 US-501：作为用户，我希望宠物动作与 Codex 图集规范一致，以便现有宠物不会错行或错帧。

### 范围

- 定义 9 个动画状态、行号、帧数量和逐帧持续时间。

### 验收标准

- Given 每个动画状态，When 查询布局，Then 行号、帧数和持续时间匹配 8×9 规范。

### 验证方式

- 核心检查断言 idle、running-right、failed 与 review 的关键数据。

### 完成定义

- 所有使用单元共享同一动画契约，无散落魔法数字。

## AT-503：发现与校验宠物包

用户故事 US-502：作为安装过 Codex 宠物的用户，我希望 HarnessDock 自动发现它们，以便直接选择使用。

### 范围

- 扫描 `~/.codex/pets` 与 HarnessDock Application Support 宠物目录。
- 校验清单、图集存在性、图集像素尺寸，并按稳定 ID 去重。

### 验收标准

- Given 多个合法包，When 刷新，Then 设置页按名称稳定列出。
- Given 损坏或尺寸错误的包，When 刷新，Then 不进入可选列表并显示摘要错误。

### 完成定义

- 只读扫描不修改源包，有效包可加载为 `NSImage`。

## AT-504：导入、选择和持久化

用户故事 US-503：作为用户，我希望导入一个宠物包并保留选择，以便重启后继续使用。

### 范围

- 用 macOS 目录选择器选择包含 `pet.json` 的文件夹。
- 复制到 Application Support，并持久化启用状态、选中 ID 和显示尺寸。

### 验收标准

- Given 合法外部包，When 导入，Then 包进入 HarnessDock 管理目录并立即选中。
- Given 应用重启，When 初始化控制器，Then 恢复之前的启用、选择和尺寸。
- Given 非法包，When 导入，Then 不留下半成品目录并显示可理解错误。

### 完成定义

- 设置可恢复，导入失败不会破坏已有包。

## AT-505：实现图集裁切动画

用户故事 US-504：作为用户，我希望看到清晰流畅的宠物动画，以便宠物对当前工作状态提供轻量反馈。

### 范围

- 按行列裁切 `1536×1872` 图集并按逐帧持续时间切帧。
- 在减少动态效果时固定显示该状态第一帧。

### 验收标准

- Given idle 状态，When 时间推进，Then 只在第 0 行 0-5 列循环。
- Given 减少动态效果已开启，When 时间推进，Then 帧索引保持 0。

### 完成定义

- 图集不拉伸变形，透明背景正确，缩放保持 192:208 比例。

## AT-506：实现安全覆盖层交互

用户故事 US-505：作为 Harness 用户，我希望宠物不妨碍页面操作，同时仍可点击互动。

### 范围

- 将宠物放在窗口右下角安全区，只让宠物视图接收命中。
- 单击触发短暂 waving，右键菜单可打开设置或隐藏。

### 验收标准

- Given 宠物已启用，When 点击宠物外的 WebView，Then 页面照常接收事件。
- Given 点击宠物，When 互动开始，Then 短暂播放 waving 后恢复应用状态动画。

### 完成定义

- 覆盖层可访问性标签存在，页面主要交互不被遮挡。

## AT-508：映射 HarnessDock 运行状态

用户故事 US-507：作为用户，我希望宠物反映 Harness 的工作状态，以便不打开日志也能感知启动、忙碌和错误。

### 范围

- 启动或页面加载映射到 running；错误映射到 failed；稳定运行映射到 idle；手动点击映射到 waving。

### 验收标准

- Given Harness 启动中，When 覆盖层渲染，Then 使用 running 行。
- Given Harness 或页面失败，When 覆盖层渲染，Then 使用 failed 行。
- Given Harness 稳定运行，When 覆盖层渲染，Then 使用 idle 行。

### 完成定义

- 状态映射为纯函数或可直接审核的计算属性。

## AT-510：生成 DeepWhale 规范动画包

用户故事 US-509：作为 DeepSeek Harness 用户，我希望宠物是一只具有 DeepSeek 识别感的蓝色小鲸，以便它与产品语境一致而不是通用角色。

### 范围

- 生成原创蓝色小鲸主参考图，并以该图为唯一身份基准生成 9 行动画。
- 使用 Codex 数字宠物的紧凑像素风、深海蓝与青蓝有限色板、圆润鲸体、白色腹部、小鳍和上扬尾鳍；不包含文字或可读商标。
- 输出 `pet.json`、透明 `spritesheet.webp`、联系表、验证 JSON；编码器可用时额外输出预览视频。

### 验收标准

- Given 最终图集，When 校验，Then 尺寸为 1536×1872、已用格非空、未用格完全透明且 QA 无 error。
- Given 任一动画行，When 与主参考图比较，Then 物种、头身比例、眼睛、腹部、鳍、尾巴和色板保持一致。

### 完成定义

- `DeepWhale` 宠物包与 QA 产物真实存在并通过视觉审核。

## AT-513：安装并选中 Marina Codex 宠物

用户故事 US-512：作为同时使用 Harness 与 Chat 的用户，我希望 Chat 页面也能使用鲸鱼女仆 Marina，以便两个页面的宠物角色保持一致。

### 范围

- 复用已经通过 hatch-pet 最终化的 Marina 包，不重复生成或修改图集。
- 将 `pet.json` 与 `spritesheet.webp` 一起安装到 `~/.codex/pets/marina`。
- 将本机 HarnessDock 的 Chat 原生宠物选择切换为 `codex:marina` 并保持启用。

### 验收标准

- Given Marina 孵化运行，When 检查任务、QA 与图集，Then 10 个生成任务全部完成、QA 无 error/warning、图集为 1536×1872。
- Given 包已安装，When 扫描 `~/.codex/pets`，Then `marina` 同时包含合法 `pet.json` 与 `spritesheet.webp`，原始包与安装包哈希一致。
- Given HarnessDock 重启，When 打开 Chat 页面，Then 已选包 ID 为 `codex:marina` 且宠物显示已启用；Harness 页插件选择不被改写。

### 完成定义

- Codex 宠物目录、HarnessDock 偏好和重启后的 Chat 加载路径均有验证证据。
