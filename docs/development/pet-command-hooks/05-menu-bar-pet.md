# 菜单栏宠物

用户明确要求宠物本身直接在 macOS 顶部菜单栏中播放动画。使用原生 MenuBarExtra，由独立的 PetMenuBarAnimator 更新菜单栏 NSImage，菜单关闭时继续播放；点击只展开设置面板，可切换宠物、打开主窗口、切换 Chat 原生宠物显示和退出应用。

菜单栏空间有限，宠物高度为 22pt，保留透明背景；菜单栏动画跟随当前页面的命令活动：Harness 页面由宠物插件通过受限的 WKWebView 消息通道上报，Chat 页面沿用原生回答状态。每次切换宠物或动作时预裁剪目标行，并按照图集逐帧时长播放；取消前一轮播放，避免并行动画计时。系统减少动态效果开启时显示首帧。菜单栏宠物独立于页面宠物开关。

验收：生产构建、签名通过；菜单栏出现宠物图标，点击显示选择器和打开应用按钮。
