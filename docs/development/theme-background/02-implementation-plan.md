## 具体案例

| 案例 | 输入或上下文 | 期望行为 | 验证方式 |
| --- | --- | --- | --- |
| 首次设置 | 选择 JPEG/PNG/HEIC | 页面立即显示居中裁切背景 | 实机 |
| 大尺寸图片 | 最长边超过 2560px | 导入副本被缩放，不直接加载原图 | 文件检查 |
| 调整遮罩 | 拖动滑块 | 当前会话即时更新且重启后保留 | 实机 |
| 移除图片 | 点击“移除背景” | 页面恢复官方背景且本地副本删除 | 实机/文件检查 |
| 无效文件 | 解码失败 | 保留旧背景并显示错误 | 代码审核 |

## 兼容与回滚

- 没有主题时不添加主题 class，官方样式保持不变。
- 删除主题 presentation、user script 增量和设置入口即可完整回滚。
- 主题文件位于 Application Support，不影响工作区和服务进程。

## Codex 5.5 审核清单

- 图片是否只落在 Application Support，且不会传给 Harness 子进程。
- 大图是否缩放，错误路径是否保留旧背景。
- 未配置主题时是否完全保持官方页面。
- 侧栏主题入口是否与现有图标网格一致。
- 构建、检查、签名和实机验证是否通过。
