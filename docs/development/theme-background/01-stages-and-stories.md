## AT-301：定义主题数据边界

用户故事 US-301：作为重视隐私的用户，我希望背景图片只保存在本机应用目录，以免进入项目或被 Harness 服务上传。

### 验收标准

- 主题图片固定保存在用户 Application Support，不保存源文件路径。
- 传给 WebView 的数据只用于 CSS 背景，不通过 Harness API 或子进程传递。

## AT-302：导入和管理图片

用户故事 US-302：作为用户，我希望选择常见图片文件作为背景，并能随时更换或移除。

### 验收标准

- macOS 文件选择器只允许图片类型。
- 导入图片最长边不超过 2560px，并以固定 JPEG 文件原子写入。
- 无效图片显示错误且不覆盖现有背景；移除后删除持久文件。
- 应用重启后自动恢复已保存背景和遮罩强度。

## AT-303：显示主题背景

用户故事 US-303：作为 Harness 用户，我希望自定义图片覆盖整个工作区背景，同时聊天文字和卡片仍清晰可读。

### 验收标准

- 图片以 `cover` 居中填充窗口，不捕获鼠标事件。
- 只透明化 Harness 根部布局容器，内容卡片和浮层保持原有层级。
- 遮罩强度调整后无需重载会话即可生效。
- 未配置图片时页面保持官方原样。

## AT-304：提供可发现入口

用户故事 US-304：作为用户，我希望从 Harness 左侧栏和 macOS 菜单都能打开主题设置。

### 验收标准

- 展开侧栏显示“主题背景”行，折叠侧栏显示同中心线的图片图标。
- 设置页提供预览、选择/更换、遮罩滑块和移除按钮。
- 主题入口不改变余额、API Key、侧栏折叠和会话行为。

## AT-305：可靠关闭主题设置

用户故事 US-305：作为主题设置用户，我希望点击“完成”后立即返回主界面。

### 验收标准

- “完成”按钮直接将控制 sheet 的 `showThemeSettings` 状态设为 `false`，不依赖间接的环境 dismiss。
- “完成”位于图片操作行的安全点击区，避免弹窗顶栏命中冲突。
- 鼠标点击和 Esc 均可关闭主题设置，不改变当前背景与遮罩值。

## AT-306：确保背景不被 Harness 布局层遮挡

用户故事 US-306：作为已设置主题图片的用户，我希望关闭设置页后能在 Harness 侧栏和主工作区看到背景，而不是仍看到纯黑页面。

### 验收标准

- 已启用主题时，动态识别并透明化覆盖窗口大部分面积的 Harness 布局容器。
- 聊天气泡、输入框、菜单和余额详情等小型内容层不被批量透明化。
- Harness 导航或侧栏折叠导致 DOM 更新后，透明化规则会自动重新计算。
- 页面首次加载或重载时会暂存主题 payload，注入桥就绪后立即应用，无需拖动遮罩滑块触发。
- 移除主题后清理标记，页面恢复官方背景。
