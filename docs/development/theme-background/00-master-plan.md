# 总开发阶段文档：自定义主题背景

## 目标

允许用户从 Mac 选择一张本地图片作为 Harness 主题背景；选择结果在应用重启后保留，并可调整内容遮罩或一键移除。

## 非目标

- 不提供在线图库、云同步、动态壁纸或多主题预设。
- 不修改官方 Harness 的主题设置和服务端数据。
- 不把用户图片写入项目工作区或 Git 仓库。

## 当前证据

- 运行态由 `HarnessWebView.swift` 的受控 user script 注入原生扩展。
- `AppModel.swift` 已负责本机设置和原生文件选择。
- 当前 macOS 菜单及注入侧栏都可承载主题设置入口。

## 假设

- “上传图片”解释为通过 macOS 文件选择器导入本地图片，并复制到 Application Support。
- 背景使用居中裁切（cover）；默认增加深色内容遮罩，避免影响文字可读性。

## 风险

| 风险 | 影响 | 缓解方案 | 负责人 |
| --- | --- | --- | --- |
| 原图过大 | WebView 内存和更新开销过高 | 导入时按最长边 2560px 缩放并压缩为 JPEG | Codex |
| 官方页面使用实体背景 | 图片不可见 | 仅将应用外壳的浅层容器改为透明，保留内容卡片 | Codex |
| Harness 新版增加深层实体布局 | 已启用图片仍被纯色背景遮挡 | 动态识别占据大面积的布局面并透明化，保留小型内容卡片 | Codex |
| 图片降低文字对比度 | 可读性下降 | 默认内容遮罩并提供强度调节 | Codex |
| 用户图片误入仓库 | 隐私泄露 | 固定保存至用户 Application Support | Codex |
