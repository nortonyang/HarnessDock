## 具体案例

| 案例 | 输入或上下文 | 期望行为 | 验证方式 |
| --- | --- | --- | --- |
| 首次打开 Chat | 点击“免费聊天” | 首次加载官网并显示进度 | 实机 |
| 返回 Harness | Harness 中已有会话 | 页面位置和任务状态保持 | 实机 |
| 再次进入 Chat | 官网已加载 | 不重新创建 WebView | 实机 |
| 官网登录 | 用户自行登录 | Cookie 由默认 WebKit 存储保留 | 实机/代码审核 |
| 外部链接 | 导航到非 DeepSeek 域名 | Safari 打开 | 代码审核 |
| 官网加载失败 | 网络或风控错误 | 可重载或在 Safari 打开 | 实机/代码审核 |

## 兼容与回滚

- Chat 首次打开前不创建公网 WebView，也不发起网络请求。
- 删除 Chat WebView、页面选择状态和标题栏入口即可回滚；Harness 路径保持原样。
- 不改动 Harness 服务端、进程树、余额凭据和主题背景存储。

## Codex 5.5 审核清单

- 两个 WebView 是否真正常驻且互不注入数据。
- Chat 是否仅加载官方 DeepSeek 域名，外部链接是否交给 Safari。
- 文件选择是否只由官网用户动作触发。
- 未打开 Chat 时是否没有公网加载。
- 构建、检查、签名和实机切换是否通过。
